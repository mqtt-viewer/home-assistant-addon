# MQTT Viewer

MQTT Viewer is a fast MQTT visualisation and debugging tool. This add-on runs
its browser interface on a Home Assistant machine and opens it through Home
Assistant ingress.

Use MQTT Viewer to connect to an MQTT broker, inspect topic trees and payloads,
and record messages. Saved connections, settings and recordings persist in the
add-on's private data directory.

Ingress keeps the interface behind Home Assistant authentication. Direct port
access is disabled by default.

See the [documentation](DOCS.md) for installation, broker connection and
security details.
